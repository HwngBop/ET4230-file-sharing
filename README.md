# ET4230 - Client Server File Sharing

## 1. Project Overview

Ứng dụng chia sẻ tệp Client–Server sử dụng TCP Socket.

Các chức năng dự kiến:
- Upload file
- Download file
- List files
- Multi-client
- Chunk-based transfer
- SHA-256 integrity verification
- Performance measurement
